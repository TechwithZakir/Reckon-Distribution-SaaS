Use Bangladesh Bangla for field screens and operational labels.

| English | Bangla |
| --- | --- |
| Distribution | ডিস্ট্রিবিউশন |
| Warehouse | গুদাম |
| Van Stock | ভ্যান স্টক |
| Retailer | রিটেইলার |
| Route | রুট |
| Due | বকেয়া |
| Collection | কালেকশন |
| Supplier | সরবরাহকারী |
| Delivery | ডেলিভারি |
| Sync | সিঙ্ক |

Keep registered product, brand, and legal entity names unchanged.
